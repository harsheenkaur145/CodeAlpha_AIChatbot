# CodeAlpha_AIChatbot

Task 3 - Java Internship - CodeAlpha

This is a simple rule-based AI Chatbot in Java.

## How it Works
- User types a message
- Bot checks keywords like hello, java, codealpha, bye
- Bot gives a rule-based answer using if-else
- Type 'bye' to exit

## Features
- Interactive chat
- Understands common questions
- Simple Natural Language Processing using keywords

## How to Run
1. Compile: javac AIChatbot.java
2. Run: java AIChatbot
